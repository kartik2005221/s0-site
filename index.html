[ Architecture ]

Five Core Forensic Capabilities

Engineered from first principles with zero external runtimes. Complete cryptographic chain-of-custody guaranteed across every sector.

[ 01 ] SANITIZATION

Defensive Media & File Sanitization

Purge or Clear physical drives, SSDs, NVMe, USB media, and individual sensitive files per NIST SP 800-88 Rev. 1 and IEEE 2883-2022. Executes direct controller commands (NVMe Sanitize, ATA Secure Erase, BLKDISCARD) or multi-pass CSPRNG overwriting.

Emits tamper-evident Ed25519-signed JSON and print-ready A4 PDF compliance certificates embedding optical verification QR codes.

NIST SP 800-88 NVMe Sanitize ATA Secure Erase DoD 5220.22-M Surgical File Shredding Thermal Monitoring
[ 02 ] CARVING

Offensive Forensic Evidence Carving

Reconstruct deleted artifacts and evidence from raw bit-stream images, formatted drives, and unallocated clusters. Employs 5 specialized carving engines parsing ext4 non-allocated inodes, NTFS $MFT runlists, FAT32 directory markers, and exFAT cluster heaps.

Every recovered artifact is evaluated using 4-factor Shannon entropy scoring, structure validation, and bifragment heuristic cluster reassembly.

ext4 Inode Carving NTFS $MFT Parsing FAT32 / exFAT Heaps Shannon Entropy Bifragment Assembly Custom Hex Signatures
[ 03 ] ACQUISITION

Bit-Stream Acquisition & Hardware Duplication

Preserve digital evidence adhering to ISO/IEC 27037 and NIST SP 800-86 standards. Acquire raw bit-stream forensic images (.raw / .dd / .img) or execute direct block-to-block drive cloning.

Calculates simultaneous live SHA-256 and MD5 checksums during sequential streaming without extra disk passes, paired with ddrescue-style bad sector zero-filling.

Live Dual Hashing (SHA256+MD5) Fault-Tolerant ddrescue Direct Drive Cloning Configurable I/O Buffers ISO/IEC 27037
[ 04 ] AUDIT LEDGER

Cryptographic Hash-Chained Audit Ledger

Every laboratory wipe, carving run, or bit-stream acquisition is anchored immutably to an append-only SQLite ledger (~/.s0/s0_audit.db).

Each block incorporates the SHA-256 hash of the predecessor block, operator metadata, and Ed25519 signature. Any post-facto modification or record deletion breaks chain continuity and triggers immediate alarms during s0 audit verify.

SHA-256 Block Chaining Append-Only SQLite Ed25519 Block Signatures Sub-Millisecond Verification Tamper-Evident
[ 05 ] ZERO-TRUST VERIFIER

Zero-Trust Client-Side Verification Portal

Verify compliance certificates instantly in pure client-side WebCrypto at s0-verify.pages.dev. Drag and drop certificate JSON files, A4 PDF reports (automatically rendered and optically scanned via PDF.js and jsQR), or raw QR code images.

100% Air-Gapped: Zero bytes or certificates ever leave your browser. Deterministic verification according to RFC 8785 (JSON Canonicalization Scheme - JCS) and RFC 8032 Ed25519 public key pinning.

100% Client-Side WebCrypto Offline Drag & Drop Optical PDF QR Extraction RFC 8785 Canonical JSON Pinned Authority Public Keys Instant Tamper Detection

[ Deployment ]

Quick Installation

One command sets up s0 with isolated virtual environment and registers it onto your system PATH.

Linux & macOS

Bash / Zsh

Detects system packages, configures Python virtual environment at ~/.s0, and symlinks ~/.local/bin/s0.

curl -fsSL https://s0-install.pages.dev/sh | bash

Windows

PowerShell

Verifies Python 3.10+, installs Win32 file shredding engine, and registers user environment variables.

irm https://s0-install.pages.dev/ps1 | iex

Windows

Command Prompt

Automated batch installer for standard Command Prompt without requiring PowerShell script permissions.

curl -fsSL https://s0-install.pages.dev/cmd -o s0-install.cmd && s0-install.cmd && del s0-install.cmd

Bare-Metal Bootable ISO

Debian 12 Live

Hybrid UEFI/BIOS live image booting into an air-gapped Chromium kiosk wipe station for locked system drives.

s0 live download && sudo s0 live flash --target /dev/sdb

In-Place Upgrade

CLI / Terminal

Pull latest cryptographic definitions, carving signatures, and core packages in place.

s0 upgrade

Clean Uninstall

CLI / Terminal

Removes binary symlinks and venv packages with an option to preserve your audit ledger database.

s0 uninstall
